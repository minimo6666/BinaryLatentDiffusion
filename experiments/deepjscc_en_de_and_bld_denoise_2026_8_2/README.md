# Frozen JSCC-25 + BLD trial (2026-08-02)

This directory is the single home for the experiment code and every generated
artifact. The existing JSCC-25 checkpoint is treated as read-only input.

## Scientific comparison

For every validation image, the experiment computes a pre-channel clean binary
code `X0` with the frozen JSCC-25 encoder. One noisy code is then generated by
16QAM, AWGN and hard demapping. The exact same noisy code is used by both paths:

```text
baseline: image -> frozen E25 -> channel -> frozen D25
ours:     image -> frozen E25 -> channel -> BLD -> frozen D25
```

Only BLD is trained. Its latent target is the clean, pre-channel JSCC-25 code.
Its second target is the original image through the frozen JSCC-25 decoder.

The BLD training observation is produced by the actual symbol-level QAM/AWGN
implementation instead of independent bit flips sampled from average BER. The
reverse posterior still uses the analytical BLD transition.

## Important choices

- The existing checkpoint was trained with 16QAM, so this experiment defaults
  to 16QAM for both BLD training and evaluation. The older plotted JSCC curve
  was evaluated with 64QAM and is copied only as a historical reference; it is
  not mixed into the new paired plot.
- BLD is trained over 0--15 dB Eb/N0. The default paired plot evaluates
  0, 4, 8, 12, 15 and 25 dB. At 25 dB, BLD uses the clean schedule endpoint and
  therefore acts as a safe bypass. Negative SNR is intentionally excluded from
  the first trial because it is outside the training support.
- JSCC-25 uses a 96 x 32 x 32 code. BLD therefore uses 1024 spatial tokens, not
  the old 256-token setting. The trial Transformer is reduced to 384 dimensions
  and 8 layers so it can fit a 24 GB GPU.
- Evaluation noise is paired. Baseline and BLD never receive two independently
  drawn channel realizations.

## Run

First run the two-step smoke test:

```bash
bash experiments/deepjscc_en_de_and_bld_denoise_2026_8_2/run_smoke_test.sh
```

Then run the trial:

```bash
bash experiments/deepjscc_en_de_and_bld_denoise_2026_8_2/run_full_pipeline.sh
```

All editable settings are together in `config.sh`. For example, after the
100-image trial confirms a gain, run a 1000-image final evaluation with:

```bash
NUM_EVAL_IMAGES=1000 bash experiments/deepjscc_en_de_and_bld_denoise_2026_8_2/run_full_pipeline.sh
```

If training was already completed, run `evaluate.py` and `plot_results.py`
directly instead of launching the full pipeline again.
